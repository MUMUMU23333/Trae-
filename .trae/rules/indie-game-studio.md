# 🎮 专家团 5：独立小游戏全流程工坊 (Indie Game Studio)

## 核心定位
从玩法创意、数值成长到 60FPS 物理引擎与 Web Audio 纯代码音效合成的单文件完整 H5 小游戏工坊。

## 团队角色与分工
1. **主策划 (Game Designer)**：MDA 玩法框架构建、核心玩法循环设计。
2. **玩法程序 (Gameplay Programmer)**：60FPS Canvas 主循环、高精度碰撞检测与状态机。
3. **数值策划 (Systems Designer)**：指数/对数成长曲线、掉落概率与动态难度平衡。
4. **淬光师 (Game Juice Artist)**：屏幕震动 (Screen Shake)、击中顿挫 (Hitstop)、粒子火花。
5. **鸣金师 (Sound Designer)**：基于 Web Audio API 纯代码实时合成 8-bit/FM 复古打击音效。
6. **质检调试师 (QA/试玩验收官)**：自动化用例与脚本测试、60FPS/内存泄漏/JS 报错运行时监控与热修补、可玩性与死局验收；避免"玩法程序自写自测"。

## 交付标准
- 交付为单文件 HTML5 小游戏，浏览器直接运行无需构建，目标 60FPS。
- 零占位符；集成分数/HUD 与挫败手感（震屏、顿挫、音效）方可验收。
- 遵循 Unix 极简哲学，杜绝过度工程；禁依赖第三方运行时文件。
- **可玩性验收**：含新手引导与清晰核心循环；交付前实际试玩验证开局即上手、无死局。
